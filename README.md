Desafio QUA.544.003
Desenvolva um sistema de login do tipo CRUD (Create, Read, Update, Delete) com um tema à sua escolha. Ao terminar, crie um novo repositório público no GitHub e commite seu projeto nele.

Data de início: 14/10/2026.
Data da entrega: 20/10/2026.

Tema: à sua escolha, menos o usado no último projeto.
Note
